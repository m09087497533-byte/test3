# v17.1: совместимый установщик для Mac

Причина обращения: pip не нашёл CTranslate2 при установке faster-whisper.
У пользователя системный CPython 3.14.2, arm64, macOS 15.6.1. Это не доказывает
версию Python внутри старой `.venv`, поэтому новый установщик проверяет именно
каждый используемый интерпретатор и выводит его версию, архитектуру и macOS.

Решение: отдельный обычный CPython 3.12 и набор бинарных пакетов для macOS 11+.
Совместимая `.venv` используется повторно; несовместимая сохраняется, рядом
создаётся `.venv-py312`. Повреждённая уже существующая `.venv-py312` не удаляется.
Системный Python, медиа, проекты и ключи не заменяются. Homebrew используется
только для установки Python 3.12, если его ещё нет. SRT/VTT доступен при отказе
дополнительного компонента; распознавание и смысловая модель ставятся отдельно.

Проверено:

Полный прогон на совместимых версиях нативных библиотек: 144 теста прошли.
После добавления проверки Homebrew повторно прошли все 9 тестов установщика.
Также прошла проверка интерфейса в настоящем Chromium (модель подменена).
Импорт нативных библиотек и декодирование настоящего WAV проверены на Linux.

- Полный набор зависимостей доступен в бинарном виде для CPython 3.12:
  `macosx_11_0_arm64` и `macosx_11_0_x86_64`. Проверены разрешение зависимостей
  и скачивание всех wheels с включённой штатной проверкой TLS.
- Регрессионные тесты: выбор 3.12, отклонение 3.14 и free-threaded Python,
  повторное использование совместимой среды, сохранение старой `.venv` и
  ключей, защита существующей sidecar-папки, отсутствие Homebrew, независимость
  дополнительных компонентов, остановка при ошибке основных зависимостей.
- Существующий тест обновления: исходники копируются с резервной копией,
  прежние `.venv`, медиа и ключи сохранены.
- Синтаксис обоих `.command` файлов.

Ограничения: бинарные файлы macOS скачаны и проверены по метаданным pip,
но не исполнялись на Linux. Запуск приложения на Mac и распознавание настоящей
речи нужно подтвердить на пользовательской машине. Ограничение Hugging Face
из отчёта v17 относится к облачной тестовой среде и не объясняет эту ошибку pip.
