# Проверка v17

Изменения реализованы поверх присланного v16. Предыдущий рассказ о готовых
129 тестах не использовался как доказательство: в исходном архиве прошли
110 тестов, распознавания речи там не было.

## Проверено

Полный набор: **136 тестов прошли**, без пропусков. До изменений: 110.

- Python API: импорт озвучки, валидация параметров, отсутствие установки,
  предел 60 минут, таймкоды сегментов и слов, пустая речь, ошибки модели,
  отмена, запоздалый результат и перезапуск сервера.
- Редактор: исправления обновляют акценты и сохраняют миллисекунды,
  длительность сцен, назначенные материалы, смещения, голос и музыку.
- Настоящий MP4: монтаж из результата тестового распознавателя, 8 секунд,
  240 кадров, звуковая дорожка полной длительности и декодируемый звук.
  Сам распознаватель в этом тесте подменён; кодирование FFmpeg настоящее.
- Chromium: пустой проект не запускает поиск; автоматический и ручной запуск,
  остановка, продолжение проверки после перезагрузки, ошибка модели,
  изоляция нового проекта от старого результата, реальное сохранение правок
  через API, скачивание SRT с точными таймкодами. Ответы распознавателя
  подменены, браузер и остальное приложение настоящие.
- Пять преднамеренных поломок в отдельных временных копиях: язык, таймкод,
  отмена, сохранение фразы, смысловой порог. Каждую обнаружил свой тест.
- Настоящая `faster-whisper`: проверены запуск дочернего процесса и обработка
  сетевого запрета при скачивании модели; пользователь получает сообщение
  «Не удалось загрузить модель», а не неясное «остановилось».
- Совместимость базовых и дополнительных Python-зависимостей (`pip check`),
  синтаксис JavaScript и Mac-скриптов.

## Не проверено / ограничения

Скачивание настоящих моделей Whisper и MiniLM в этой облачной машине
заблокировано прокси (`403 Forbidden`). Распознавание настоящей речи,
качество смысловой оценки и скорость на Mac **не проверены**. Синтетические
тесты интерфейса и ранжирования не доказывают точность моделей.

В черновике сетевых настроек сохранены добавления:

- `huggingface.co`
- `cdn-lfs.huggingface.co`
- `cas-bridge.xethub.hf.co`
- `cas-server.xethub.hf.co`
- `transfer.xethub.hf.co`

Для проверки моделей в облаке нужно проверить и сохранить изменения в
настройках среды, затем опубликовать среду. Сохранение черновика само по себе
не изменило сеть текущей машины. На Mac используются его сетевые настройки.
Для повторной проверки после разрешения доступа используйте короткую запись
с известным текстом, сначала модель tiny, затем small; проверьте имена,
таймкоды, завершение озвучки и экспорт целиком.

Модель оценивает текст и метаданные, не содержимое изображений. Общий поиск
по ключевым словам и старые тематические правила сохранены; подбор подходящего
кадра для любой темы не гарантирован. Без источников или ключей стоков
отдельные сцены могут остаться незаполненными. Настоящая пользовательская
озвучка, её итоговый фильм, Safari и macOS в этом прогоне недоступны.

## Команды

Из папки приложения, после установки `requirements-dev.txt`:

```bash
.venv/bin/python -m unittest discover -s tests
.venv/bin/python scripts/check_v17_mutations.py
```

Проверки Chromium дополнительно требуют `requirements-ui.txt` и установленный
Chromium в PATH:

```bash
.venv/bin/python scripts/check_new_project_ui.py
.venv/bin/python scripts/check_speech_ui.py
```
