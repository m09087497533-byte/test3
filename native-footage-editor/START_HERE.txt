ПЕРЕХОДЫ И ТЕКСТОВЫЕ АКЦЕНТЫ v2. ЗАПУСК: python3 main.py

ЧТО НОВОГО

Семь новых переходов добавлены к прежним эффектам. Отметь нужные чекбоксы:
выбранные эффекты повторяются по кругу в порядке списка, как раньше.
Поиск и назначение футажей работают прежним способом.

«Текстовые акценты · автоматически» добавляет даты, числа и короткие фразы
из озвучки/субтитров поверх футажей. «План акцентов» показывает их заранее.
Обычно достаточно 2 крупных акцентов в минуту; можно выбрать 0–4.
Звуки выключены. При включении они звучат только в момент появления текста.
Смена футажа сама по себе звука не получает.

При обновлении сохрани .env, .venv-local и папки проектов. Замени исходники
и обязательно добавь всю папку accents со шрифтами. Для новых эффектов
дополнительная установка библиотек не нужна, если программа уже запускалась.

1. Закрой старую программу и замени файлы содержимым этого комплекта.
   Перенеси ВСЕ файлы, включая bootstrap.py, setup_local.py и local_models.py.
   Свой .env с ключами Pexels/Pixabay сохрани. Папки проектов не удаляй.
   Старые параметры FASTGEN_* в .env больше не используются.

2. Ошибка «No module named _tkinter» означает, что в установленном Python
   отсутствует компонент для окон. Для этой версии один раз выполни:

   brew install python@3.12 python-tk@3.12 ffmpeg

   Это добавит подходящий Python с Tkinter. Переименовывать системный python3,
   менять алиасы и удалять установленный Python 3.14 не нужно.

3. Открой Терминал в папке, где находится main.py.
   Можно напечатать cd и пробел, перетащить папку в Терминал и нажать Enter.
   Затем один раз выполни:

   python3 setup_local.py

   Установщик найдёт Python 3.12 с Tkinter, создаст рядом .venv-local
   и установит библиотеки. Он не ставит их в системный Python и не
   перезаписывает существующий .env. Установка может занять время.

4. В дальнейшем запускай как раньше:

   python3 main.py

   Эта команда сама подхватит подготовленное окружение. Вручную активировать
   его, запускать Install.command или Start.command каждый раз не нужно.

ЧТО РАБОТАЕТ ЛОКАЛЬНО

- Распознавание речи: faster-whisper. Можно по-прежнему импортировать SRT/VTT.
- Перевод русских фраз для поиска: локальная модель Marian RU→EN.
- Сравнение текста и кадров: локальная модель CLIP.
- Монтаж: FFmpeg.

Нет запросов к FastGen, Gemini или другим платным API распознавания/анализа.
Аудио и кадры для анализа не отправляются облачному ИИ. Поисковые запросы
отправляются Pexels/Pixabay, откуда скачиваются видео и превью.

При первом использовании функции скачивается её модель с Hugging Face.
Нужен интернет и несколько гигабайт свободного места на модели и библиотеки.
Первый подбор и первая транскрибация могут запускаться заметно дольше.
После загрузки анализ выполняется на ноутбуке. Интернет всё равно нужен
для поиска и скачивания новых футажей. Первая загрузка весов не требует
платной подписки/API-ключа.

КАК ПОДБИРАТЬ

Открой аудио, транскрибируй его или импортируй субтитры. Нажми «Подобрать все
футажи». Для пересмотра прежнего подбора — «Переподобрать сток».
Для отдельной сцены доступны «Искать футаж», «Ещё варианты», ручной выбор
и «Свой файл». Поле «Свой запрос для поиска» позволяет уточнить сцену по-русски
или по-английски; оно применяется при нажатии «Искать футаж»/«Ещё варианты».

Текущий текст имеет основной вес при сравнении. Контекст соседних сцен
и ключевые слова темы имеют меньший вес. Поиск использует несколько запросов,
объединяет сайты, убирает дубликаты, сравнивает превью, затем три кадра из
каждого лучшего проверяемого клипа. Если совпадений нет, расширяет поиск.

Число под карточкой — сходство CLIP, умноженное на 100, а не процент точности.
Локальная модель слабее большой языковой модели в понимании отрицаний,
метафор, конкретных исторических событий и личности героя. Она сравнивает
видимое сходство, а не подтверждает достоверность кадра. Запросы формируются
по локальному переводу и ключевым словам, без генеративного анализа сюжета.

Если все проверенные клипы ниже порога, сцена помечается для ручной проверки.
Автоматически случайный клип не назначается. При переподборе старое назначение
остаётся до успешной замены. Локальные файлы и ручные выборы новой версии
сохраняются; в старых проектах признак ручного выбора стока не записывался.

ПАРАМЕТРЫ (необязательно добавлять в .env)

WHISPER_MODEL=base            небольшой вариант по умолчанию; small точнее, тяжелее
WHISPER_LANGUAGE=ru          русский язык
SEARCH_PER_PROVIDER=6        результаты каждого сайта на запрос
LOCAL_PREVIEW_LIMIT=12       превью на этап поиска
LOCAL_FRAME_LIMIT=4          клипы для проверки трёх кадров на этап
LOCAL_MIN_SIMILARITY=0.22     порог сходства; ниже — больше автоматических выборов

Локальный кеш отдельный: selection_cache_local внутри папки проекта.
Старые сохранения читаются. Исправления пауз и растворений сохранены.

настоящего окна Tkinter, включая сборку видео кнопкой. Все пройдены в Linux.
