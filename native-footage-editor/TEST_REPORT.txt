AI Footage Editor — переходы и акценты v2

РЕЗУЛЬТАТЫ ЭТОГО ОБНОВЛЕНИЯ

17 тестов tests/test_editing.py — пройдены, Python 3.12, FFmpeg 7.1.5.
3 теста tests/test_native_gui.py — пройдены, Python 3.13, Tk 8.6, Xvfb.
Это настоящее окно Tkinter; браузерная эмуляция не использовалась.

Проверены:
- прежний порядок первых 11 эффектов и циклическая раздача старых/новых;
- все 7 новых переходов в настоящем MP4: декодирование, 25 fps,
  число кадров, наличие аудио, цвета до/во время/после перехода;
- обычная склейка перед xfade и цветной переход на границе блоков сборки;
- паузы без удвоения, расчёт 500 сцен без накопления сдвига;
- полный текст отрицания через две реплики, лимиты акцентов, отсутствие
  выдуманных чисел, три оформления дат, неподвижная сетка;
- отсутствие мерцания после появления, единая фаза акцента через склейку;
- нулевой PCM вне окон появления текста; тишина вне этих окон также
  проверена в декодированном AAC финального MP4 с тихой исходной дорожкой;
- отключение текста отключает и его звуки; по умолчанию звуки выключены;
- включение звуков не задерживает исходную озвучку (сравнение двух MP4);
- старые проекты: клипы, кандидаты, запросы, ручные назначения и эффекты
  сохраняются; новые настройки переживают сохранение и открытие;
- повторяющийся текст при переимпорте сохраняет свои футажи по порядку;
- ошибка обработки не уничтожает прежний экспорт;
- окно: 18 чекбоксов, импорт настоящего SRT, настройки, прокрутка,
  блокировка при работе, превью акцентов, реальная сборка кнопкой окна.

СРАВНЕНИЕ С ПРИСЛАННЫМИ ИСХОДНИКАМИ

Двенадцать файлов, включая footage.py, semantic.py, network.py,
local_models.py, transcribe.py, subtitles.py и установщик, не изменены
побайтно. Девять обработчиков поиска/назначения/импорта и assign_effects
сверены по AST: логика не изменена. Хеши — PRESERVED_SOURCE.json.
В файлах .command сохранён текст, добавлено право выполнения в комплекте.

ДЕМОНСТРАЦИЯ

ai-footage-editor-transitions-v2-demo.mp4: настоящая сборка build_video,
1280×720, 25 fps, 32 секунды, 800 кадров, восемь сцен и два цикла из
четырёх выбранных эффектов. Иллюстрации собственные. Исходное аудио — тишина,
поэтому слышны только необязательные акценты. Частота крупных акцентов
для показа установлена 4/мин; обычное значение программы — 2/мин.

ЗАПУСК ТЕСТОВ

Из папки с main.py:
  .venv-local/bin/python -m unittest discover -s tests -v

Без графического дисплея 3 оконных теста пропускаются. В Linux можно
запускать их через Xvfb; на Mac — в обычной графической сессии.

ГРАНИЦЫ ПРОВЕРКИ

В загруженном старом TEST_REPORT.txt говорилось о 37 тестах и запуске
Marian/CLIP/Whisper. Файлы тех тестов в загрузке отсутствовали. Этот отчёт
не повторяет их результаты как проверку новой версии. Стоковые ключи и
реальные модели заново не запускались; качество поиска не переоценивалось.
Mac/Homebrew на компьютере пользователя здесь не проверялись.
Текстовые акценты основаны на правилах и приблизительном времени слов
внутри реплики; точное повторение монтажа референса не заявляется.
